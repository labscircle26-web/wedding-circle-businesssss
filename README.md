# Wedding Circle Business

India’s Wedding Professional Directory — Discover. Connect. Grow.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router

## Getting Started

```bash
npm install
npm run dev
```

## Pages Implemented (Milestone 1)
- Homepage (editorial hero, categories, featured)
- Explore Professionals (search + filters)
- Professional Profile
- Business Registration / Onboarding UI
- Business Dashboard UI
- Admin Dashboard UI

## Design
- Deep Burgundy `#6E2433`
- Champagne Gold `#C4A574`
- Warm Ivory `#F6F1E8`
- Soft Blush

## Notes
- Uses structured mock data for professionals.
- Search, filtering, and navigation are fully functional.
- Enquiry forms, authentication, uploads, and payments are UI-ready for future backend integration.
- Currency defaults to INR.
- Built mobile-first and responsive.

This is a standalone product focused exclusively on wedding professionals and business discovery.
